# Global Electronics Retailer Sales Analysis using Power BI

## Project Overview

This project focuses on analysing sales data for a global electronics retailer using Microsoft Power BI. The objective is to explore sales performance, understand customer purchasing patterns, analyse product performance, and generate meaningful business insights through interactive dashboards.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV Dataset

## Dataset Overview

- Dataset: Global Electronics Retailer
- The dataset contains information related to sales transactions, customers, products, stores, and geographical locations.

## Data Cleaning and Transformation

The following data preparation activities were performed:

- Checked data quality and identified missing values.
- Cleaned and transformed data using Power Query.
- Reviewed data types and column consistency.
- Prepared the data model for analysis.
- Created relationships between relevant tables.

## Key Areas of Analysis

- Overall Sales Performance
- Product Category Analysis
- Product and Brand Performance
- Customer Analysis
- Store Performance
- Geographical Sales Analysis
- Sales Trends and Patterns

## Business Objectives

- Understand overall business sales performance.
- Identify top-performing products and categories.
- Analyse customer purchasing behaviour.
- Compare sales performance across stores and locations.
- Identify sales trends and business opportunities.
- Support data-driven business decisions.
